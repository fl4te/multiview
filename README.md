# Multiview - Twitch & YouTube

**Multiview** is a clean, modern, single-page web application that lets you build your own custom streaming command center. Watch multiple Twitch channels and YouTube live streams or videos simultaneously, manage individual audio feeds, and switch between live chats seamlessly.

## Features

* **Dual-Platform Support:** Stream from both Twitch and YouTube in the same grid.
* **Smart URL Parsing:** Paste full stream URLs (e.g., `https://twitch.tv/channelname` or `https://youtube.com/watch?v=...`) or just type a channel name.
* **Flexible Layouts:** Switch instantly between **Auto**, **2×2 Grid**, **3×3 Grid**, and **Spotlight Mode**.
* **Independent Audio Controls:** Easily mute or unmute individual streams with a single click. (New additions auto-mute to prevent overlapping audio chaos).
* **Integrated Chat Panel:** Toggle the sidebar chat and dynamically switch between the chat rooms of any active stream.
* **URL State Synchronization:** Your active layout and streams are automatically saved to the URL hash, making it easy to bookmark or share your exact multi-stream setup with friends.
* **Fully Responsive:** Adapts gracefully from multi-monitor desktop setups down to mobile screens.

---

## Supported Input Formats

You can type or paste any of the following into the address bar:
* **Twitch Channels:** `channelname` or `https://twitch.tv/channelname`
* **YouTube URLs:** `https://www.youtube.com/watch?v=VIDEO_ID` or `https://youtu.be/VIDEO_ID`
